# Орбита — Telegram Mini App

Бесплатное русскоязычное мини-приложение: нумерология, интерактивная психоматрица, символическая совместимость, код ресурсов, авторская игра на 36 клеток по мотивам Лилы и личный дневник. Монетизации, оплаты и закрытых разделов нет.

## Запуск на компьютере

Нужен Node.js 24. Зависимости устанавливать не требуется.

```sh
node scripts/serve.mjs
```

Откройте http://127.0.0.1:4188. Остановка сервера — Ctrl+C. Не открывайте index.html напрямую через file://: браузер блокирует JavaScript-модули.

```sh
node --test
node scripts/build.mjs
```

Готовый сайт находится в `dist/`. Все ссылки относительные: поддерживаются и корень домена, и `/tgminiap/`. Навигация использует hash, поэтому перезагрузка раздела не требует серверных правил.

## Публикация в anastasiamayer54/tgminiap

Исходники приложения находятся в этом репозитории. Публикация сайта настраивается отдельно в **Settings → Pages**.

### Самый простой способ — через сайт GitHub

1. Откройте репозиторий под аккаунтом с правом записи. В пустом репозитории нажмите **uploading an existing file** (в непустом — **Add file → Upload files**).
2. Загрузите из проекта шесть файлов: `index.html`, `styles.css`, `app.js`, `core.js`, `favicon.svg`, `.nojekyll`. Они также лежат в папке `dist/`. Файлы должны лежать прямо в корне репозитория, без внешней папки. Зафиксируйте в ветку `main`.
3. Откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, нажмите **Save**.
4. Дождитесь завершения публикации. Ожидаемый адрес: https://anastasiamayer54.github.io/tgminiap/ — он заработает только после публикации.

### Автоматическая публикация через Actions

В проекте уже есть `.github/workflows/pages.yml`. Загрузите весь исходный проект в `main` с сохранением этой скрытой папки. В **Settings → Pages → Source** выберите **GitHub Actions**. Выполните workflow **Publish Orbita to GitHub Pages** из вкладки Actions (Run workflow), если он не запустился автоматически. Workflow запускает тесты, собирает `dist/` и публикует только файлы приложения.

Для загрузки через Git после авторизации:

```sh
git init -b main
git add .
git commit -m "Add Orbita Telegram Mini App"
git remote add origin https://github.com/anastasiamayer54/tgminiap.git
git push -u origin main
```

Эти команды предназначены для исходно пустого репозитория. Если там уже появился код, сначала клонируйте актуальный репозиторий и перенесите файлы приложения; не используйте force push.

## Подключение в Telegram

1. В официальном **@BotFather** создайте бота командой `/newbot`, если его ещё нет. Имя и username выбирает владелец.
2. Отправьте `/setmenubutton`, выберите своего бота. Укажите название кнопки, например **Открыть Орбиту**, и опубликованный HTTPS-адрес GitHub Pages.
3. При желании назначьте приложение основным: `/mybots` → ваш бот → **Bot Settings → Configure Mini App → Enable Mini App**. Используйте тот же адрес; точные подписи зависят от языка интерфейса BotFather.
4. Откройте чат с ботом и нажмите кнопку меню. Проверьте запуск внутри Telegram на телефоне. Для проверки обычного интерфейса бот не нужен — приложение работает и в браузере.

Не добавляйте токен бота в код, репозиторий, URL или сообщения Codex. Для статического Mini App токен в браузере не нужен. Серверная авторизация, ответы бота на сообщения и рассылки в этот проект не входят. Для кнопки запуска достаточно настроек BotFather.

Официальные инструкции: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Поведение и данные

- Telegram SDK: `ready()`, `expand()`, цвета окна и тактильный отклик при доступности. Сайт работает и при недоступном SDK. Telegram initData не используется как подтверждение личности.
- Дата рождения (1900 — сегодня), дата партнёра, игра и заметки сохраняются в localStorage. Они не отправляются на сервер приложения и не синхронизируются между устройствами. Встроенный браузер Telegram и обычный браузер могут иметь разные хранилища.
- В дневнике есть экспорт JSON, удаление отдельной записи и всех данных с подтверждением. Экспорт предназначен для резервной копии и чтения; автоматического импорта пока нет. При закрытом хранилище приложение сообщает, что сохранение недоступно.
- PDF: откройте **Мой разбор → Сохранить в PDF / печать**, затем выберите **Сохранить как PDF** в системном диалоге. В некоторых Telegram WebView печать недоступна — откройте тот же сайт во внешнем браузере и введите дату заново.
- Никакой аналитики, рекламных SDK, внешних шрифтов и серверного AI. Единственный внешний скрипт — официальный SDK Telegram; сервер GitHub Pages и Telegram обрабатывают сетевые запросы по своим политикам.

## Формулы

Число пути: сумма цифр даты и последующее сложение цифр до 1–9, с сохранением 11, 22, 33. Психоматрица: цифры даты + четыре рабочих числа; первое — сумма цифр даты, второе — сумма цифр первого, третье — первое минус удвоенная первая цифра дня (день без ведущего нуля), четвёртое — сумма цифр модуля третьего. Нули не учитываются. Разные школы могут использовать другие варианты.

Личный год: сумма цифр дня, месяца и текущего календарного года, сведённая к 1–9. Общая тема пары: сумма чисел пути, сведённая к 1–9. Код ресурсов: день, месяц и сумма цифр года по отдельности, сведённые к 1–9. Игра: случайный кубик 1–6, переходы явно указаны в правилах, финиш на 36 при достижении или превышении.

Трактовки — символические вопросы для самопознания, а не научная диагностика или прогноз. Код ресурсов не предсказывает доход. Поле Лилы сокращено и является авторской адаптацией, а не классической версией игры.
